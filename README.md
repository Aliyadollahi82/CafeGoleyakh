# 🍦 Cafe Gole Yakh

A modern and responsive website for **Cafe Gole Yakh**, designed to showcase the cafe's ice cream and beverage menu with a clean and attractive user interface.

## 🌐 Live Demo

[View Website](https://cafe-gole-yakh-frontend.vercel.app/)

## 🛠️ Technologies

* Next.js 16
* React
* Tailwind CSS
* JavaScript / TypeScript
* HTML5
* CSS3
* Responsive Design

## ✨ Features

* Modern and attractive cafe design
* Fully responsive layout
* Mobile, tablet, and desktop support
* Ice cream and beverage menu
* Product image showcase
* User-friendly interface
* Persian RTL layout
* Smooth navigation between sections
* Responsive order button

## 📱 Responsive Design

The website is optimized for different screen sizes:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet

## 🚀 Getting Started

First, install the project dependencies:

```bash
npm install
```

Then, start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## 📦 Deployment

The project is deployed on **Vercel**.

[View Live Project](https://cafe-gole-yakh-frontend.vercel.app/)
